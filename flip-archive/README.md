# 世界のFLIP図鑑 — WORLD FLIP ARCHIVE

世界中の「常識をひっくり返した企画・作品・介入・事件」を、分野の境界を越えて記録するアーカイブ。
株式会社こす.くま『世界のFLIP図鑑 収録・編集方針 v0.2』（2026年8月）に基づく実装。

## 構成

| ページ | 内容 |
| --- | --- |
| `/` | 図版の帯。ドラッグ／ホイールで送り、ホバーで版の配置操作が走る。クリックで詳細へ。 |
| `/cases` | 索引。図版一覧（OVERVIEW）と表一覧（LIST）、6軸＋配置操作での絞り込み。「変容前／実行後」で全図版を見比べられる。 |
| `/case/[slug]` | CASE詳細。方針文書 §7 の公開項目に対応。 |
| `/about` | 収録・編集方針。 |

## 図版について

実物の写真は権利処理が必要なため、**掲載していない**。各CASEの図版は WebGL で生成した「配置図」で、
`src/webgl/shaders.ts` に **CASEごとの作図プログラム**を持つ（共通のパターン生成器ではない）。
図版は静止時に《変容前の配置》を、`uProgress` が上がると《配置操作の実行後》を描く。

- 帯の描画: `src/webgl/Ribbon.tsx`（Three.js + GSAP、FOV 5°の超望遠カメラ、無限ループ）
- 単票の描画: `src/webgl/plateRenderer.ts` + `src/components/Plate.tsx`（共有レンダラから各キャンバスへ転写）
- CASEと作図プログラムの対応: `src/lib/plateParams.ts`

## 編集の原則（実装にも反映）

- **三つの文章を混ぜない** — 実行主体による説明／確認できた事実／こす.くまのFLIP読解 を別フィールドに分け、詳細ページでも刷り分ける。
- **点数・順位・レアリティを付けない** — 判断ラベルは編集作業上の状態のみ（`flipStatus` / `publishStatus`）。
- **対立・不明はそのまま公開する** — `notes` に未確認事項と対立情報を残し、出典は `confirmed` で本文到達の有無を区別する。

## 開発

```
npm install
npm run dev      # 既定は 3000。他プロジェクトと衝突する場合は --port で指定
npm run build
```

運用は monorepo 共通の GitHub Flow に従う（master 直 push 禁止、branch → PR → プレビュー → マージ）。
